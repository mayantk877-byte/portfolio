## 🚀 How to Run the Portfolio

The portfolio is structured in standard, high-performance, runnable formats:

### Option 1: Direct Double-Click (Zero Dependencies)
- Double-click `index.html` in file explorer or drag & drop it into any web browser (Chrome, Edge, Firefox, Safari).
- All styles, icons, images, and JavaScript features will run instantly offline and online.

### Option 2: Run with Node.js Server (Included)
Run the built-in, zero-dependency server:
```bash
node server.js
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser.

### Option 3: Run with npm / npx
```bash
npm start
# or
npm run dev
```

### Option 4: VS Code Live Server
- Right-click `index.html` inside VS Code and click **"Open with Live Server"**.

## ✨ Features Included

1. **Balanced, Normal & Professional Color Scheme**:
   - **Executive Dark Theme**: Midnight Slate (`#090e17`) + Sapphire Royal Blue accents (`#2563eb`, `#38bdf8`) with high contrast text for optimal readability.
   - **Corporate Clean Light Theme**: Snow White (`#f8fafc`) + Royal Blue (`#1d4ed8`) with soft shadows and readable dark slate text.
   - Persistent theme toggling stored in `localStorage`.

2. **100% Working Icons**:
   - Integrated Font Awesome 6 with verified solid and brand glyphs (`fa-house`, `fa-user`, `fa-graduation-cap`, `fa-code`, `fa-laptop-code`, `fa-award`, `fa-envelope`, `fa-phone`, `fa-location-dot`, `fa-github`, `fa-linkedin-in`, `fa-chart-pie`, etc.).

3. **Fully Responsive Across All Devices**:
   - **Mobile (320px - 480px)**: Animated hamburger drawer menu, auto-collapsing floating badges, stacked action buttons, touch-friendly tap targets.
   - **Tablet (481px - 768px)**: Adaptive 2-column grids, readable cards, smooth scroll.
   - **Desktop & Laptops (1024px+)**: 3D mouse tilt effect, floating badges with ambient glow rings, full navigation bar with active ScrollSpy indicators.

4. **Interactive Showcase & Features**:
   - **Dynamic Typing Header**: Cycles through professional designations with realistic typing and backspacing cadence.
   - **Interactive Project Filtering**: Instant category tabs for *All Projects*, *Data Analytics*, *Web Development*, and *JS Applications*.
   - **Project Preview Modal**: Clicking "Live Demo" or "View Details" opens a rich modal dialog with full description, tech stack tags, and repository link.
   - **Click-To-Copy**: Clicking email or phone automatically copies it to clipboard with instant toast notifications.
   - **Interactive Contact Form**: Features instant feedback, validation, sending state spinner, and toast notifications.
   - **Back to Top Floating Button**: Smoothly returns to top when scrolling down.
